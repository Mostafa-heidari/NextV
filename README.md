# Mostafa Heidari — personal website

A responsive personal website based on Mostafa's supplied résumé and interests. Built with HTML, CSS, JavaScript, and Vite; no backend or credentials needed.

## Development

Use Node.js 22.12+ or 24 LTS.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static host. Email links open the visitor's email application. The site uses local sans-serif fonts and requires no external font requests.

## Content

Edit `index.html` for biography, experience, and contact links, and `src/style.css` for presentation. The portrait was extracted from the supplied résumé. Career dates are approximate Gregorian equivalents of the résumé's Solar Hijri dates. The résumé does not confirm a graduation date for the master's studies or an end date for the CEO role; the site preserves that uncertainty. Private home address, birth date, and marital/military status are omitted.
